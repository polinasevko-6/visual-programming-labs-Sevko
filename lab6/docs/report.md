# Отчёт по лабораторной работе №6 (Kodular)

## 1. Краткое описание
Создано мобильное приложение «Приветствие» на платформе Kodular. Приложение содержит поле для ввода 
имени, кнопку и логику проверки. Если поле пустое, выводится сообщение об ошибке, если заполнено 
— приветствие. На экране размещена фамилия студента (Sevko).

## 2. Ссылка на проект / .aia
Файл `lab6-Sevko.aia` находится в папке `exports/`.

## 3. Использованные AI-промпты
- «Как в Kodular сделать проверку на пустоту текстового поля?»
- «Как использовать блок join для соединения строк в Kodular?»
- «Как экспортировать проект из Kodular в .aia?»

## 4. Освоенные компоненты и блоки
- **Компоненты:** Label (для заголовка, вывода результата и фамилии), TextBox (поле ввода), Button 
(кнопка).
- **Блоки:** `when Click`, `if then else`, логическое `=`, `Text_Box1.Text`, `join`, `set Label1.Text to`.

## 5. Ограничения бесплатного тарифа Kodular
В бесплатном тарифе действуют ограничения: до 10 проектов, до 10 МБ ассетов (изображений, звуков) 
и до 5 расширений (extensions). Для базового задания этих лимитов достаточно.

## 6. Выводы
В ходе работы я освоила создание мобильного приложения в Kodular. Поняла, как работает визуальное 
программирование с помощью блоков (как в Scratch). Научилась обрабатывать нажатия кнопок, проверять 
условия и выводить текст на экран. Самым сложным было собрать блоки `if/else` и `join` так, чтобы 
логика работала правильно.
