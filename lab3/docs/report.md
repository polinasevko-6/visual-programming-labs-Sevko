# Отчёт по лабораторной работе №3 (Bubble)

## 1. Краткое описание выполненного
В ходе работы я освоила платформу Bubble (no-code). С помощью AI-агента 
я сгенерировала каркас приложения «Каталог растений», вручную доработала 
UI (заголовок, глобальная переменная цвета, новый стиль, компонент), 
создала базу данных (Data Type "Care Task") и реализовала CRUD 
(создание, чтение и удаление записей) через Workflows на отдельной странице.

## 2. Промпт для генерации (дословно)
Создай приложение на тему «Каталог растений».
Пусть этот сайт будет публичный.
Страницу обязательно создай по структуре header + body + footer.
Обязательно укажи в заготовке следующую строку: «ТВП: Севко».
Добавь несколько интерактивных элементов (реализующих CRUD).

## 3. Ссылка на dev-версию приложения 
https://bubble.io/page?id=my-app-261026-50445&open_chat=true&tab=Preview&name=index&type=page

## 4. Использованные AI-промпты
- Промпт для генерации каркаса (см. выше).
- Промпт для создания сущности: «Создай сущность для базы данных под 
названием "Care Task". Добавь 3 поля: "Task Name" (текст), "Due Date" 
(дата), "Is Completed" (да/нет)».
- Промпт для создания страницы CRUD: «Создай новую страницу (page) под 
названием "care_tasks". Размести на ней заголовок "Задачи по уходу". 
Ниже добавь повторяющуюся группу (Repeating Group), которая выводит все 
записи из "Care Task"... [и т.д.]».

## 5. Освоенные элементы и workflows
- **Элементы UI:** Text, Button, Input, DatePicker, Checkbox, 
Repeating Group, Popup.
- **Workflows:** Create, Delete, Reset inputs (сброс полей формы).
- **Данные:** Data types (Care Task), App data (ручное добавление записей).
- **Стили:** Global variables (primary-color), создание собственного стиля 
кнопки.

## 7. Выводы
В ходе работы я познакомилась с платформой Bubble и поняла, 
как работают no-code приложения. Мне понравилось, что AI-агент может 
сгенерировать интерфейс за секунды, но все равно требуется ручная настройка 
(например, чтобы создать глобальные переменные или настроить Workflows). 
Я научилась связывать базу данных с интерфейсом: создавать формы, 
выводить списки через Repeating Group и настраивать удаление записей 
по кнопке. Это дает понимание того, как устроены веб-приложения изнутри.
