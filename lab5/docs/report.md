# Отчёт по лабораторной работе №5 (Чат-боты)

## 1. Краткое описание трека
Выбран трек **C (TypeBot)**. В ходе работы я создала чат-бота на основе готового шаблона 
«Lead Generation» (Сбор лидов). Бот переведен на русский язык, в него добавлены условия (Condition), 
переменные (Variable) и интеграция с внешним API (HTTP Request).

## 3. Использованные AI-промпты
- «Как в TypeBot перевести шаблон на русский язык, чтобы не сломались переменные?»
- «Как добавить условие (Condition) в TypeBot для проверки заполнения поля Email?»
- «Как настроить HTTP Request в TypeBot для получения случайного факта о котах?»

## 4. Освоенные блоки и элементы
- **Bubbles (Сообщения)** — вывод текста.
- **Inputs** — поля ввода (Name, Email).
- **Condition** — ветвление логики (проверка, заполнена ли почта).
- **Variable** — использование переменных `{{Name}}`, `{{Email}}`, `{{CatFact}}`.
- **HTTP Request** — GET-запрос к стороннему API.
- **Theme** — настройка цветов и брендинга.

## 6. Выводы
В ходе работы я освоила создание чат-бота в TypeBot. Платформа позволяет без кода проектировать
сценарии общения, использовать ветвления и подключать внешние сервисы через HTTP. 
Самым сложным было настроить передачу ответа от API в переменную, но это помогло понять, как боты 
работают с реальными данными из интернета.
