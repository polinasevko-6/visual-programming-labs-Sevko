# Отчёт по лабораторной работе №7 (Notion)

## 1. Предметная область и модель данных
Выбрана предметная область «Учёт студенческих проектов».
**Сущности:**
1. **Проекты** — название, статус, дедлайн, оценка.
2. **Задачи** — название, статус, дедлайн, связь с проектом.
3. **Студенты** — имя, группа, почта, связь с проектом.

**Связи (Relation):**
- Задачи → Проекты.
- Студенты → Проекты.

## 2. Промпт для ИИ и его ответ
**Промпт:** «Придумай модель данных для учёта студенческих проектов. 3 сущности: Проекты, Задачи, 
Студенты. Свойства: Title, Select, Date, Number, Relation. Добавь сложную формулу с if и датами для 
отслеживания просроченных задач».
**Ответ ИИ:** Сгенерирована модель с тремя таблицами и связями. 
**Что исправлено:** Настроены реальные связи через Relation, добавлена формула 
`if(and(prop("дедлайн") < now(), prop("статус") != "завершён"), "⚠️ Просрочено", "✅ В порядке")`.

## 3. Ачивка №8: Сложная формула
В базе «Задачи» добавлена колонка `Статус срока`. Формула проверяет, если дедлайн в прошлом и статус 
не «завершён», выводится «⚠️ Просрочено», иначе «✅ В порядке».
