# API Документация (Лабораторная 2)

## 1. GET /api/text
Возвращает простой текст.
**Пример запроса:** `http://localhost:1880/api/text`
**Ответ:** `Привет от студента! Это простой текст.`

## 2. GET /api/info
Возвращает JSON с информацией о студенте.
**Пример запроса:** `http://localhost:1880/api/info`
**Ответ:** `{"student": "Sevko", "group": "ТВЛ"}`

## 3. GET /api/items
Возвращает данные товара по ID.
**Параметры:** `id` (query param) — идентификатор товара.
**Успешный запрос:** `http://localhost:1880/api/items?id=1`
**Ответ (200 OK):** `{"item": "Яблоко", "price": 100}`
**Запрос с ошибкой:** `http://localhost:1880/api/items?id=2`
**Ответ (400 Bad Request):** `{"error": "Неверный ID"}`
