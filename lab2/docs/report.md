# Отчёт по лабораторной работе №2 (Node-RED)

## 1. Краткое описание выполненного
В ходе работы я установила Node-RED через npm и освоила создание потоков
(flow). Были выполнены все 12 пунктов базовой части: от простого
inject-debug до работы с API, Dashboard и Telegram-ботом. 
Все потоки сохранены в формате JSON в папке `flows/`, для каждого 
сделан скриншот.

## 2. Использованные AI-промпты
При выполнении работы я использовала ИИ для генерации кода и подсказок. 
Примеры промптов:
- «Сгенерируй код для Node-RED Function node, который использует let/const, 
if/else, цикл for, массив и объект, и возвращает результат в msg.payload».
- «Как в Node-RED настроить Switch node, чтобы он проверял значение 
msg.payload на равенство числу 20 и отправлял в два разных выхода?».
- «Напиши Mustache-шаблон для Node-RED Template node, который формирует 
JSON из объекта с полями name, lab, status».

## 3. Освоенные ноды
В ходе работы я освоила следующие ноды:
- **Базовые:** inject, debug, function, switch, change, template.
- **Сетевые:** http request, mqtt in, mqtt out, http in, http response.
- **Dashboard:** gauge, chart.
- **Telegram:** telegram receiver, telegram sender.
- **Файлы:** write file, read file.

## 4. Способ установки и версии
- **Способ установки:** npm (установка через терминал, так как Docker Desktop 
выдавал ошибку виртуализации).
- **Версия Node-RED:** v4.x.x
- **Версия Node.js:** v20.x.x

## 6. Выводы
В ходе выполнения лабораторной работы я научилась работать с Node-RED как 
с инструментом low-code программирования. Я поняла, как передаются 
сообщения (msg) между узлами, как использовать контекст 
для сохранения данных и как создавать собственные 
API-эндпоинты.Node-RED позволяет быстро создавать прототипы без 
написания большого количества кода.
