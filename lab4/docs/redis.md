# Работа с Redis в n8n

## Подключение
Redis запущен в Docker-контейнере на порту 6379. В n8n создано подключение (Credentials) с 
параметрами:
- **Host**: `host.docker.internal` (для доступа из контейнера n8n к Redis на хост-машине)
- **Port**: `6379`
- **Password**: (пусто)

## Создание и чтение ключа
Был создан workflow `flow-07-redis`:
1. **Manual Trigger** — ручной запуск.
2. **Redis (Set)** — создание ключа `sevko` со значением `My Redis Test`.
3. **Redis (Get)** — чтение ключа `sevko`.
4. **Code** — вывод результата.
Результат: значение успешно прочитано (`My Redis Test`).

## Удаление ключа
Был создан workflow `flow-08-redis-delete`:
1. **Manual Trigger** — ручной запуск.
2. **Redis (Delete)** — удаление ключа `sevko`.
3. **Redis (Get)** — попытка прочитать ключ (проверка отсутствия).
4. **Code** — вывод результата.
Результат: ключ не найден (вернулось `null`), что подтверждает успешное удаление.
