# Отчёт по лабораторной работе №8 (Xano)

## 1. Предметная область и модель данных
Выбрана предметная область «Учёт студенческих проектов».
**Сущности:**
1. **Projects** — название, статус, дедлайн.
2. **Tasks** — название, статус, дедлайн, связь с проектом.
3. **Students** — имя, группа, почта, связь с проектом.

**Связи (Relation):**
- Tasks → Projects.
- Students → Projects.

## 2. Промпт для ИИ и его ответ
**Промпт:** «Создай бэкенд для учёта студенческих проектов. Нужно 3 таблицы: Projects, Tasks, Students. 
Создай CRUD-эндпоинты для Tasks».
**Ответ ИИ:** Сгенерирована структура таблиц и базовые CRUD-эндпоинты.
**Что исправлено:** Настроены типы полей, созданы связи (Reference), добавлен кастомный эндпоинт для 
пагинации.

## 3. Ачивка №2: Пагинация и сортировка
Реализован эндпоинт **`/tasks/paginated`**. 
- Добавлены входные параметры: `page`, `per_page`, `sort`.
- В настройках функции `Query All Records` настроена пагинация и сортировка.
- **Ограничение тарифа:** На бесплатном тарифе Xano динамические параметры для пагинации недоступны, 
поэтому использованы фиксированные значения (Page=1, Per Page=5), а сортировка по полю `name`. При 
переходе на платный тариф эти значения заменяются на переменные.
